# 残夏 -The Last Tide-

> 汐浦町，最后一个夏天。一个关于懂事、照护与留下的人的悲剧恋爱冒险。

现实主义悲剧向恋爱 ADV（视觉小说），**Godot 4.7** 制作，全中文。
2013 年 6 月 17 日 — 9 月 19 日，一个正在退潮的渔村小镇上，
一个高三男生遇见了一个决定不治疗自己的女孩。

## 玩法

就是读。点点屏幕推进，偶尔选一次。

| 操作 | 键鼠 | 触屏 |
|---|---|---|
| 推进对话 | 点击 / `Space` / `Enter` | 点屏幕 |
| 打开回想 | `Ctrl`+`R`，或 HUD「回想」 | HUD「回想」 |
| 快速跳过 | `Ctrl`，或 HUD「跳过」 | HUD「跳过」 |
| 自动播放 | HUD「自动」 | HUD「自动」 |
| 打开菜单 | `Esc`，或 HUD「菜单」 | HUD「菜单」 |

- **跳过**默认不分已读未读一律跳过；想改成「只看过的才跳」，去设置里取消勾选「跳过时忽略未读文本」。
- 标题画面右侧会轮播全部立绘，**点不同部位（脸 / 胸 / 肚子 / 手臂）会说不同的话**。
- 结局共 **5 个**（1 True / 2 Normal / 2 Bad），分支由你在第五章末的一句话决定。

## 工程结构

```
Zanka/                       Godot 工程（可直接用 Godot 4.7 打开）
  data/                      剧本与数据（JSON）
    story/main.zs            剧本源文件（自定义 .zs DSL）
    story/main.json          编译产物，游戏实际读这个
    endings.json             五个结局的展示文本
    systems.json             信件 / 照护日志 / 时段
    tides.json               汐浦港潮汐表（序章就埋了终章的伏笔）
  scripts/
    core/                    ui_theme.gd（全套设计令牌）、ui_kit.gd、zs_compiler.gd
    ui/                      UI 全部由 GDScript 运行时构建
    autoload/                GameState / SaveManager / StoryEngine / AudioManager / GameConfig
  assets/                    立绘 13 / 背景 18 / CG 5 / BGM / 环境音 / 字体（子集化）
  tools/                     剧本编译、校验、出图、抠图、字形检查、导出（Python）
残夏_企划书/                  七篇企划文档
```

> **注意**：`Zanka/tools/` 里有 `.gdignore`，Godot 会整目录跳过，不会被导出。

## 自己构建

```bash
# 仓库里已带 .gitignore：build/ 与 release/ 不入库
cd Zanka
bash tools/export_all.sh      # 导出 APK + Windows + Linux（需要 Godot 4.7.2 与对应导出模板）
python3 tools/validate.py     # 静态校验（剧本/符号/常量/资源引用）
python3 tools/check_font_coverage.py scripts/ui/*.gd   # 检查文案有没有字体里没有的字
```

**中文字体是子集化的**（只收录打包时项目文本里出现过的字），
所以往游戏里写任何新汉字前，都要先跑 `check_font_coverage.py`，
否则那个字在真机上会显示成豆腐块 □。

## 已知情况

- 企划里的**三周目结构、时段递减机制、照护日志三条路**目前只实现了戏份与数据层，
  **没有做成分支**；现在是一条主线走到底 + 3 个选择点 + 5 个结局。
  详见 [残夏_剧情概括](残夏_剧情概括.md) 最后一节。
- 立绘由本机离线模型生成、BiRefNet 语义抠图，**张与张之间存在风格差异**。
- 本作没有语音。
