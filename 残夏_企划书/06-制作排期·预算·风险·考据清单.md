## 二、18 个月排期

| 阶段 | 时长 | 交付物 |
|---|---|---|
| **P0 原型** | 2 个月 | 对话 DSL、潮汐系统、序章 demo（可玩 30 分钟）、美术风格验证 |
| **P1 前期制作** | 3 个月 | 全角色设定定稿、全 7 章大纲定稿、**医疗与制度考据完成**、BGM 主题旋律、样板场景（04 文档样本 1/4/5） |

| **P3 打磨** | 3 个月 | 配音录制、演出润色、三周目解锁逻辑、全结局测试、本地化 |

**里程碑 3 个（不可省）**
1. **M1（第 5 月）**：序章可玩 demo —— 验证「日常流能不能让人坐得住」
2. **M2（第 12 月）**：前四章贯通 —— 验证「机制化失去」是否被玩家感知
3. **M3（第 16 月）**：全结局测试 —— **必须找 20 个测试者，观察二周目的情绪反应**（这是本作成败的唯一标准）

| 项目 | 区间 |

## 五、真实考据清单（P1 阶段必须完成，缺一项不上马）

### 医疗线
- [ ] 日本**心脏移植**制度：日本臓器移植ネットワーク的登记流程、等待期实际分布、儿童与成人差异
- [ ] **LVAD（左心室辅助装置）**：适应标准、禁忌、并发症、费用、补助（高额疗养费制度）
- [ ] **扩张型心肌病**的自然病程：为什么患者可以在代偿期看起来完全正常（**这是全作合理性的地基**）
- [ ] **家族性**心肌病的遗传咨询实际流程（她哥哥的死因是否会被追问）
- [ ] 透析的工作量与生活半径（每周 3 次、每次 4 小时、往返 2 小时意味着什么）
- [ ] **指定难病** / **小儿慢性特定疾病** 医疗费补助的申请门槛与自付上限
- [ ] **脑死亡判定**流程与**器官捐献意愿书**的法律效力（日本臓器移植法）
- [ ] 地方诊所的**转诊**实际流程与患者负担

### 照护线
- [ ] **介护保险**：要介护认定流程、主治医师意见书、调查员上门、1–5 级区分
- [ ] 认知症老人「傍晚综合征」的实际应对（作为剧本素材）
- [ ] 居家照护者的支援制度与实际缺口（**本作主题的现实依据**）
- [ ] 町役场的窗口设置与办事体验（用于 05 文档的「填表格」设计）

### 社会线
- [ ] **废校**与町村合并的实际流程、居民表决、学生转学安排
- [ ] **共同渔业权**与渔船份额：能不能卖、卖给谁、值多少（第五章感情戏的依据）
- [ ] 水产加工厂倒闭时代的**欠薪**与地方债务
- [ ] 消费者金融 / 债务整理 / 保证人的实际处境（桐生线的依据）
- [ ] 汐浦町方言（不逐字写，但语序与语气词必须对）

### 文化线
- [ ] 十五夜（中秋名月）的习俗与供品
- [ ] 日本海侧渔村的葬仪与海葬习俗
- [ ] 2013 年日本的手机与网络环境（LINE 的普及率、地方信号覆盖）

## 六、「不合理陷阱」清单（剧本禁止出现）

这是保证「没有极不合理的地方」的负面清单。写每一场戏之前都要过一遍：

1. ✗ 排队三天就有心脏 —— 现实是极长的等待。她的死因设计为「等待期间的致命心律失常导致脑缺氧」，而非「等不到心脏」
2. ✗ 绝症患者每天跑两小时兼职却毫无症状 —— 必须有明确的**代偿期**设定与逐章递减的体力表现（见 05 文档病征演出）
3. ✗ 医生一句「她只剩三个月」 —— 现实里医生不会这么给预后，只会给方案与风险
4. ✗ 所有人瞬间理解并原谅三浦家 —— 浜口源治必须真的恨了三十年
5. ✗ 富人是纯恶、穷人是纯圣 —— 桐生有他的孤独，母亲美咲有她的理由
6. ✗ 男主是全能的 —— 他必须有一次关键的沉默（第三章看到药袋不问），并为此后悔一生
7. ✗ 钱的问题靠「大家凑一凑」轻松解决 —— 信封凑的是**葬礼与还款**，**救命的钱永远差得远**，这才是现实
8. ✗ 她的病被写成「性格好就不会得」 —— 疾病与道德无关
9. ✗ 用配乐强行制造眼泪 —— 14 处 `[MUTE]` 是硬性规定
10. ✗ 让玩家觉得「选对选项就能救她」 —— 核心悲剧不可逆，这是本作的论点，不是设计缺陷

## 七、伦理声明（必须写进企划书，并对外公开）

1. **本作的器官捐献描写，遵守「不将捐献者工具化」的原则。** 栞的捐献意愿是**她自己在清醒状态下签署的**，且剧情明确表示：她的价值不在于她救了几个人。
2. **认知症、透析、贫困，不作为「感动的素材」使用。** 所有相关场景必须咨询当事者或从业者，避免猎奇与苦难消费。
3. **不宣扬「牺牲自我是美德」。** 全作的论点恰恰相反：**栞的「懂事」是她的悲剧，不是她的优点。** True End 中悠人的成长正是否定了她。
4. **不在结尾暗示「自杀或放弃治疗是合理的解决方案」。** 她的选择被明确写为**被迫的、错误的、令人痛心的**，并且是造成所有人痛苦的直接原因。
5. 游戏内提供现实支援信息入口（照护者支援、器官捐献官方渠道），置于「特典 / 资料」菜单。
6. **医疗顾问与照护从业者的审核意见，在致谢中具名感谢。**
