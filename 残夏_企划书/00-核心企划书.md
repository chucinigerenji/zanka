# 《残夏》 The Last Tide
### 2D 剧情冒险 / 视觉小说 · 完整企划书

> 「汐浦町，最后一个夏天。」
> 副标题候选：*のこりの夏* / *After the Tide*

---

## 0. 一句话概念

**一个在衰败海港小镇照顾失智祖母的少年，遇见一个把「不治疗」当成送给家人的礼物的少女；在那个夏天里，两个人都在悄悄为对方安排「没有自己的以后」。**

## 2. 主题：这不是一个「绝症恋爱故事」

绝症恋爱是外壳。真正要写的是四个命题，每一个都来自现实生活：

1. **「懂事」是一种被美化的剥夺。**
   被夸懂事的孩子，其实是失去了求助的权利。栞的所有悲剧，都建立在「我不能麻烦别人」这句话上。
2. **照护的社会成本被转嫁给了家庭里最没有议价权的人。**
   悠人的祖母、栞的母亲、滨口的孙子——小镇靠「人情」维系，而人情同时是债务与监视。
3. **留下来的人才是悲剧的承受者。**
   死者的故事在一夜之间结束，活着的人要用剩下的四十年去习惯一个空位。
4. **记录即抵抗。**
   游戏里所有的信、日记、照护手册，都是一个人对抗「被遗忘」的方式。玩家最后拿到的那本手册，是栞留给悠人的爱，也是一份极其冷静的、关于如何照顾另一个老人的技术文档。

**核心命题（游戏向玩家提出的问题）：**
> 把自己从别人的生命里删掉，算不算爱？

**游戏最终给出的回答（藏在 True End 里）：**
> 爱不是替对方省下自己，而是让对方有资格欠你。

## 3. 为什么它不会「玩一下就腻」

| 机制 | 说明 |
|---|---|
| **三周目结构** | 一周目是温柔日常恋爱；二周目解锁「栞视角」，同一批场景全部长出第二重含义；三周目在「全知」条件下重做选择 |
| **机制化的失去** | 「时间编排」系统里，每天可选时段从 3 → 2 → 1 → 0 逐章递减。不用一句台词解释她病得多重，玩家自己就能感觉到 |
| **爱的代价可被数值化** | 陪她 = 她少打工 = 治疗费不够 = 她被迫接受那个男人的钱。玩家的温柔真的会加速她 |
| **玩家共同创作遗书** | 每章末可写一封「不会寄出的信」，全篇信件最终拼成的那封遗书，每一周目都不一样 |
| **潮汐表** | 现实潮汐与日期绑定，退潮才能去的防波堤与沉船；终章是朔望大潮——地理本身就是剧情杀 |
| **可反复解读的留白** | 她至少有 11 句台词从不说破，二周目才知道是什么意思。这是「重看一遍会痛」的设计 |

## 4. 情绪设计：不是哭一次，是哭三次（三种不同性质的哭）

| 阶段 | 情绪性质 | 触发 |
|---|---|---|
| 第二章末 | **酸**（鼻酸，忍住） | 祖母在一瞬间清醒，认出了孙子长大了 |
| 第四章 | **堵**（说不出的无力） | 老医生说出「我这里只能看感冒」 |
| 第五章 | **热**（被善意击中，最意外的泪点） | 镇上被欠过薪的老人们，一个接一个递出信封 |
| 终章 | **崩**（不可逆的失去） | 脑死亡判定 + 那本照护手册 |
| 后日谈 | **余**（平静地流泪） | 多年后，东京的教室里，一个学生问他为什么做这一行 |

「悲壮」不等于「惨」。惨是命运碾压一个人；悲壮是**她在明知代价的前提下，主动选了一件有重量的事，并为此付清了自己的那份账**。

## 5. 对标与差异化

**对标吸收：**
- 《千恋万花》：小镇肌理、日常密度、方言与祭典的质感、角色「可爱」的服务性设计（本作保留：日常做得足够好，悲剧才有重量）
- [REFLEXIA](https://store.steampowered.com/app/1997680/?l=schinese)：单一封闭空间的心理压迫、黑白孤独感、**视角不可靠**（本作二周目沿用其手法，但没有病娇与惊悚）
- 《CLANNAD》：家庭与照护的重量
- 《四月是你的谎言》：隐瞒 → 第二遍观看的痛
- 《AIR》：宿命与余韵的收尾方式

**差异化（三点，也是宣传的三张牌）：**
1. **机制化失去**：把「她正在消失」做成系统，而不是文案。
2. **双视角二周目**：一周目的每一场甜蜜，二周目都是她在硬撑。
3. **制度级真实感**：移植等待、介护保险、指定难病补助、废校、渔船份额、债务整理——全部有据可查（见 06 文档考据清单）。

## 6. 创作红线（我们不做什么）

- ✗ 不做超自然、不做轮回、不做幻觉世界
- ✗ 不做「奇迹痊愈」、不做「其实她没死」的伪悲剧结局
- ✗ 不用「医生说她只剩三个月」这种廉价的倒计时
- ✗ 不把富人写成纯恶、不把穷人写成纯圣
- ✗ 不用 BGM 硬拉情绪。本作规则：**最痛的地方要安静**
- ✗ 不写后宫、不写卖肉、不写无意义的选择支
