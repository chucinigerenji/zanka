## 你要做的三步

### 第 1 步：安装导出模板（只需一次）

模板文件在：`/storage/emulated/0/Godot导出模板/Godot_v4.7.2-stable_export_templates.tpz`

在 Godot 编辑器里：

- **编辑器（Editor）菜单 → 管理导出模板（Manage Export Templates） → 从文件安装（Install from File）**
- 在文件选择器里进到 `Godot导出模板/`，选那个 `.tpz`

> 如果编辑器里没有「从文件安装」，也可以直接把 `.tpz` 拷到编辑器提示的模板目录；
> 但用菜单安装是最省事的。

### 第 2 步：打开工程

工程管理器里应该已有 `Zanka`（如果列表里没有：**导入（Import）→ 选
`/storage/emulated/0/deepseek harness盒子/Godot/Zanka/project.godot`**）。

### 第 3 步：导出

**工程（Project）→ 导出（Export）**，然后：

| 目标 | 预设名 | 输出文件 |
|---|---|---|
| 安卓手机 | `Android` | `Zanka/build/Zanka.apk` |
| Windows 电脑 | `Windows Desktop` | `Zanka/build/Zanka.exe`（单文件） |
| Linux 电脑 | `Linux/X11` | `Zanka/build/Zanka.x86_64` |

选好预设 → 确认底部**导出路径** → 点 **导出项目（Export Project）**。

关于 **Use Gradle Build** 这个勾选项：

- 你设备上装了 Godot 的 **Gradle 构建环境 App**，所以**默认勾着就行**（这是官方推荐的安卓设备内导出方式）；
- 如果报 **SDK / JDK / gradle 相关**的错，就**取消勾选**再试一次（改走预编译模板 + apksigner 的路线）；
- 两种都失败时，把报错原文发我，我来改预设。

## 导出后怎么用

**APK**：把 `Zanka/build/Zanka.apk` 拷到手机（或平板）上点安装，需要允许「未知来源」。
它是 **arm64-v8a**，你这台平板就是这个架构 ✓。

**Windows**：`Zanka.exe` 一个文件就是完整的（游戏数据已内嵌），双击即玩，**不需要装 Godot**。

**Linux**：`chmod +x Zanka.x86_64` 然后运行。

## 如果你有电脑，也可以一键导出

在装了 **Godot 4.7.2 标准版 + 对应导出模板**的电脑上，把整个工程拷过去，然后：

```bash
cd Zanka
bash tools/export_all.sh
```

脚本会依次做：导入资源 → 导出 APK → 导出 Windows → 导出 Linux，全部落到 `build/`。
（脚本里可以改 `GODOT=` 指定 godot 可执行文件路径。）

> 注意：**安卓导出还需要 Java SDK 17 和 Android SDK**（Build-Tools + Platform）。
> 电脑上第一次导出前，要在 Godot 的 **编辑器设置 → 导出 → Android** 里填好这两个路径。
> 导出 Windows / Linux 则**不需要**任何 SDK。
